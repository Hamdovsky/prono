## 6️⃣ RÈGLES DE SURSÉLECTION (Contrarian Rules)

### Checklist "Ne pas suivre la foule"
- [ ] Le favori est-il déjà qualifié ? → Réduire confiance de 15-20%
- [ ] L'équipe à domicile joue-t-elle sa survie ? → Augmenter confiance de 10-15%
- [ ] Les deux équipes sont-elles éliminées (dead rubber) → Méfiance maximale
- [ ] Le vote public est-il >60% pour un favori sans enjeu ? → Contrarian pick
- [ ] Match de Série B brésilienne ? → Toujours couvrir le nul à domicile

### Pièges classiques Promosport
1. **Le favori mort** — Une équipe déjà qualifiée (ou éliminée) avec 70%+ des votes → PIÈGE
2. **Le match sans enjeu** — Dead rubber = match amical, ne pas se fier aux stats
3. **La B team** — Une équipe qualifiée qui fait tourner son effectif
4. **Le désespéré** — Une équipe éliminée qui joue pour l'honneur peut créer la surprise
5. **Le nul oublié** — Dans les matchs à enjeu fort, le nul est souvent sous-estimé par le public
